# STall Public Business Page Templates

## Frozen template policy

As of 2026-09-21, the public business-page templates are frozen at v1.

### Restaurant v1
Used for the current restaurant template mapping.
- STall branded header
- Business hero
- STall Verified badge
- Rating
- WhatsApp / Call / Order or Book / Directions
- Today's Special
- Everyday Special
- Location
- Hours
- Menu / Specials
- Current Offer

### Salon v1
Used for salon businesses.
- STall branded header
- Business hero
- STall Verified badge
- Rating
- WhatsApp / Call / Book Now / Directions
- Today's Offer
- Weekend Offer
- Services
- Location
- Hours
- Current Offer

## New category rule

When a new business category is introduced, do not modify the frozen Restaurant v1 or Salon v1 skeletons.

Instead:
1. Define a dedicated category template.
2. Define category-specific fields and calls to action.
3. Preview and test the new template.
4. Add the category-to-template mapping.
5. Freeze that template as its own version.

Existing live category templates must remain unchanged unless a deliberate version change is approved.

## Regression rule

If an existing template already works, protect it. New category work must be additive and must not alter the existing Restaurant or Salon page structure, branding, routing, or functionality.
